# Symulator lokalizacji źródła metodą TDOA w kanale hydroakustycznym

Projekt przejściowy – Akademia Marynarki Wojennej, Wydział Mechaniczno-Elektryczny.

## Opis

Symulator komputerowy do lokalizacji źródła dźwięku pod wodą (okrętu podwodnego) metodą różnic czasu przybycia (TDOA) w jednorodnym kanale hydroakustycznym.

## Wymagania

- Python 3.8+
- Biblioteki: numpy, scipy, matplotlib

## Uruchomienie

pip install -r requirements.txt
python tdoa_simulator.py

## Wyniki

Po uruchomieniu w folderze `results/` zostaną zapisane obrazy: mapa GDOP i wynik lokalizacji.
